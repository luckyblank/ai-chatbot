# 一、商家问题分类

平台商家客服应先把问题归入可处理队列：入驻和资质、商品发布、交易履约、营销价格、消费者投诉、知识产权、违规处置、保证金结算、账号安全或规则咨询。不同队列需要不同证据和审批权限。

# 二、入驻与资质核验

平台应收集并核验经营者身份、地址、联系方式和必要行政许可，建立档案并定期更新。客服不能只根据聊天中发送的图片确认高风险资质，应通过平台正式提交和审核流程处理。

涉及食品、医疗、生命健康或其他需要许可的商品和服务时，应提高审核级别。资质过期、主体不一致或疑似伪造时，停止自动通过并转人工审核。

# 三、规则和处置透明度

平台服务协议和交易规则应当便于经营者和消费者查看。规则发生重要修改时，应按适用法律和平台制度履行公开征求意见、提前公示等程序。

对商家采取警示、限制、下架、暂停或终止服务时，客服应说明：适用规则、认定事实、证据摘要、处置范围、生效时间、整改要求、申诉入口和处理时限。不得只回复“系统判定”或拒绝提供任何可申诉信息。

# 四、商家申诉材料

受理申诉时建议收集：商家编号、处置记录编号、争议商品或订单、申诉理由、能够反驳认定事实的材料、期望结果。材料必须通过受控渠道上传，涉及消费者个人信息时应脱敏。

申诉审核应把原处置与申诉复核适当分离。客服可以解释流程和补充材料要求，但不能在复核完成前承诺撤销处罚。

# 五、知识产权通知与反通知

权利人提出侵权通知时，应要求其通过正式入口提交身份信息、权利证明、定位信息和初步证据。平台收到合格通知后，按规则采取必要措施并通知相关商家。

商家认为不存在侵权时，可以通过申诉流程提交不存在侵权的声明和初步证据。客服不得自行判断复杂权利归属，也不得把一方提交的敏感材料无条件发送给另一方，应按法务和平台流程处理。

# 六、交易与投诉记录

平台应依法保存商品服务信息和交易信息，并确保完整性、保密性和可用性。客服在消费者争议中应积极协助核验订单、支付、物流、售后和沟通记录，但只展示解决当前问题所必需的信息。

投诉处理要有可追踪状态：待受理、材料待补充、审核中、已升级、处理完成和复核中。每次状态变化都应记录时间、操作者和依据。

# 七、个人信息最小化

个人信息处理必须具有明确合理的目的，并与处理目的直接相关。客服查询客户或商家资料时，只读取解决当前问题所需字段；不得把完整联系方式、身份证件、支付信息或其他无关数据直接展示在回答中。

# 八、回复口径示例

“已核实到本次处置关联规则为【规则名称】，当前认定事实为【事实摘要】。您可以在【入口】提交【材料清单】申请复核。复核期间我不会提前承诺撤销结果，但会保留本次沟通和材料提交记录。”
