# 企业客服知识库种子资料

本目录保存从权威公开资料整理的 RAG 种子文档。正文是面向客服实际工作的中文摘要，不是对来源网页的逐字复制。

- `01-电商售后与消费者权益处理手册.md`：对应电商售后服务。
- `02-SaaS故障响应与客户沟通手册.md`：对应 SaaS 客户成功与故障升级。
- `03-企业IT服务台与账号安全处理手册.md`：对应企业 IT 服务台。
- `04-平台商家治理与申诉处理手册.md`：对应平台商家运营。

每份文件都包含适用范围、版本日期、风险边界和官方来源。生产使用时，应继续加入企业自己的合同、SLA、退换货政策、平台规则和内部审批流程；企业内部规则与公开资料冲突时，应由法务和业务负责人确认最终口径。
