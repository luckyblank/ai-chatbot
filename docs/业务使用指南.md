# 企业智能服务中心：业务使用指南

## 这套系统解决什么问题

企业客服通常需要在多个系统之间切换：一边与客户沟通，一边查订单、查权益、翻产品手册，再把结果记录到工单。企业智能服务中心把这些动作集中到同一个对话工作台，并把每次知识检索、工具调用和模型生成过程保留下来，方便客服复核，也方便负责人追踪处理依据。

系统适用于以下角色：

- 一线客服：处理咨询、物流、退换货、退款初筛与投诉分流。
- 客户成功：处理企业租户开通、订阅服务、权限和故障升级。
- IT 服务台：处理员工账号、权限、设备与内部服务请求。
- 平台运营：处理商家服务、材料补充、申诉和运营工单。
- 知识管理员：维护产品手册、服务政策、SOP 和公告。
- 业务负责人：制定场景建议步骤，查看工具调用与处理链路；保存场景配置需要 `ADMIN` 角色，可由管理员代为配置。

## 登录

使用 `dev` 配置且未指定初始管理员凭据时，首次创建的账号可用于本地体验：

- 账号：`admin`
- 密码：`Admin@123456`

首次启动前可以设置自己的管理员凭据：本地开发在 `ai-chatbot-service/.env.development` 中添加 `DEFAULT_ADMIN_USERNAME` 和 `DEFAULT_ADMIN_PASSWORD`；Docker Compose 部署在项目根目录的 `.env.docker` 中设置 `SERVICE_ADMIN_USERNAME` 和 `SERVICE_ADMIN_PASSWORD`；直接运行后端时设置 `DEFAULT_ADMIN_USERNAME` 和 `DEFAULT_ADMIN_PASSWORD` 环境变量。正式部署应使用强密码。初始账号只在同名账号不存在时创建；修改这些配置不会重置已有账号的密码。登录状态默认保留 24 小时；若登录失效，页面会自动返回登录页。

## 发起一次客服对话

进入“会话中心”后，先选择业务场景，再核对“知识范围”。初始场景配置不预选知识库；管理员可以为场景设置可用范围及默认知识库，默认库仅在新会话预选。同一场景的不同会话可以选择不同的知识库组合，应以当前会话显示的知识范围为准。每条会话最多选择 3 个知识库，切换组合会开始一条新会话。

- 不选择知识库：仅在场景知识策略允许时按普通智能对话处理，仍可在业务场景允许的范围内查询客户、订单或工单；知识库“必选”的场景至少要选一个。
- 选择一个或多个知识库：系统只在本次选中的知识库内检索；尚无已完成索引文档的库会跳过，其余库仍可提供证据。回答显示每条引用的来源库与完整链路。回答明确标注 `[资料 N]` 时，“参考来源”只展示这些编号对应的短原文摘录；没有标注时显示“检索候选”，避免把向量召回误认成已证实的引用。同一文档可有多个摘录，Markdown 尽量标出章节，PDF 标出页码。摘录用于快速定位，重要结论仍应打开原文核对。

“通用智能助手”可直接处理编程、写作、翻译、总结、学习辅导和一般分析，不需要补充企业客服背景。为避免越权，该场景不开放客户、订单和工单等业务工具；需要查询真实业务数据时，请切换到对应的业务场景。业务工具由后端按场景白名单提供，页面上的场景说明不是唯一的权限边界。

推荐的处理顺序：

1. 选择最接近的业务场景。
2. 如果问题依赖企业政策或产品资料，核对预选的知识库并按需调整；跨库问题只勾选确实需要的几个库。
3. 输入问题；有截图、合同摘录或说明文件时，可以一并添加附件。
4. 无业务工具的回答会实时显示；开放业务工具的场景会先完成工具调用，再逐段显示回答。内容较长时，消息区独立滚动，底部输入区始终可见。
5. 回答完成后，查看下方的“链路追溯”，确认检索范围、命中片段、工具动作和模型耗时。
6. 涉及创建工单、退款、权限或合同变更时，确认系统已要求用户明确授权。

生成期间可以点击“停止”中断本轮回答；已有文字会保留并标记为已中断，可以重新生成或同步会话后继续。引用、工具调用结果和完整追溯会在本次回答正常结束后统一展示，避免把尚未完成的中间状态误认为最终结论。

### 回答内容与图表

- 回答支持常用 Markdown，包括标题、引用、链接、有序/无序列表，以及表格和任务列表。
- 代码块会保留格式，并提供常用语言高亮和复制按钮。
- Markdown 图片会直接显示在回答中，点击可放大预览；行内公式和独立公式块由 KaTeX 排版。
- 使用 `mermaid` 代码块可以展示常用流程图和时序图。流式生成时先显示图表源码，回答完成后再渲染图形，避免半段语法造成画面反复跳动。

### 附件与图片

- 支持图片、PDF、TXT 和 Markdown。
- 待发送图片只显示小预览图，不显示文件名和大小。
- 点击小图可放大查看；点击右上角关闭。
- 发送后附件会保存到会话，重新打开会话仍可查看。
- 单次最多 10 个附件，单个附件不超过 20 MB。

### 会话管理

- 第一次提问成功后，系统会根据问题内容自动生成简洁的会话名称；仍可随时手动修改。
- 每条会话右侧都有独立的操作区，可修改名称或删除，不会遮挡会话标题。
- 只有名称确实超出可用宽度时才会截断；此时悬停会自动横向滚动，短标题保持静止。
- 删除前会出现二次确认；确认后消息和会话附件一并删除，无法恢复。
- 左侧主菜单可展开或收起，系统会记住上一次选择；切换浅色或深色主题时，左侧菜单与主内容区会同步换色。
- 右侧会话上下文中的“编辑场景”会直接打开当前会话所选中的业务场景。

## 真实客服业务场景

### 电商售后服务

用于订单状态、物流进度、退换货和退款初筛。可直接提供订单号；若只知道客户编号，可先查询该客户最近 20 笔订单，再确认目标订单、核对履约状态。查询结果会标明是否仍有更早订单；若有，应补充订单号、商品或时间线索，不能把这 20 笔当作全部订单。客服登录账号的 userId 是操作员身份，不是客户编号，也不能用来反查客户订单。订单查询受业务主体授权限制。

选择售后知识库后，系统会检索政策证据；当前资格工具只做保守初筛，结果仍需人工复核，不会自动认定可退款或可退货。“创建服务工单”只准备待确认草案，正式创建必须由已登录用户确认。场景中的处理步骤是建议，不保证模型逐项执行；应查看链路追溯核对实际调用结果。

可用于体验的脱敏样例：

- 客户：`CUST-10002`
- 订单：`ORD-20260918-001`

### SaaS 客户成功

用于企业租户、订阅服务、成员权限和故障升级。当前工具可查询租户服务档案、已知订单号对应的服务订单和工单进度；尚未接入按租户编号查询订阅账单或实时用量的数据接口。无法恢复时可以准备支持工单草案，由用户确认。

可用于体验的脱敏样例：`TENANT-2001`。

### 企业 IT 服务台

用于员工账号、权限、软件、设备和网络请求。当前工具可查询员工服务档案和工单进度，尚未接入资产清单或实时权限系统。高权限申请不能由模型直接执行，必须进入审批或人工处理节点。

可用于体验的脱敏样例：`EMP-3108`。

### 平台商家运营

用于店铺服务、结算差异、处罚说明、申诉材料和处理进度。当前工具可查询商家服务档案和已有工单，尚未接入实时结算或处罚明细接口；系统不会承诺审核结果，也不会绕过风控规则。

可用于体验的脱敏样例：`MER-8802`。

### 制度与产品知识检索

用于查找产品手册、服务政策、操作流程和公告。建议选择知识库；如果不选择，系统仍按普通聊天处理，不会阻止提问。

已内置“制度与产品知识检索手册”知识库，包含本产品的知识上传、索引状态、引用查看、制度版本核验建议和典型问答。选择此业务场景后，应核对“知识范围”是否已选同名手册；未选时手动选择，并确认文档索引状态为 `READY`。可以尝试提问“知识中心支持上传哪些文件格式？”或“文档显示 PENDING_AI 时应该怎么办？”。企业正式制度仍需由知识管理员上传；手册未提供请假天数、报销限额等企业专属条款。

## 知识中心

### 创建和上传

1. 点击“新建知识库”，按业务边界命名，例如“商城售后政策”或“协作云运维手册”。
2. 可以把多个 PDF、TXT 或 Markdown 文件拖入上传区，或点击上传区一次选择多个文件；单文件上限为 20 MB。上传结果会逐个显示，个别文件失败不影响其他文件继续上传。
3. 等待状态变为“可用”。处理失败时可查看原因并重新索引。

知识库创建后仍可点击“编辑信息”修改名称和描述。修改这些资料不会删除已上传文档，也不需要重新索引；只有文档内容发生变化时才需要重新处理。

建议把不同权限、不同业务线或不同有效期的资料放在不同知识库，避免回答时混用。

### 查看原文和分词片段

在文档列表点击“预览”图标：

- “原文预览”用于核对实际上传内容。
- “分词片段”显示向量检索使用的文本片段、顺序、页码和字符数。

当回答引用某个文件时，可回到这里核对原文和分片是否合理。如果片段过旧或内容错误，应先更新知识文件，再重新索引。

## 工作流编排

系统预置四条常见流程：

- 电商售后分流
- SaaS 故障升级
- IT 服务请求
- 商家申诉处理

每个工作流由输入、条件判断、知识检索、业务工具、人工确认和结果输出等节点组成。拥有 `ADMIN` 角色的用户在工作流管理页点击“新建工作流”或“打开设计器”时，系统会直接在新的浏览器标签页打开独立设计器，原管理页继续保留。可以修改节点名称、说明、类型和顺序，也可以新增或删除节点。

编排区提供两种查看方式：

- 列表模式：适合逐项修改节点内容和顺序，也是窄屏和手机上的默认编辑方式。
- 画布模式：基于 Vue Flow 展示节点和处理顺序，可拖动节点整理布局、缩放或平移画布；内置画布控件和缩略图，也可一键自动布局。

设计器会占满整个页签。左侧节点库和右侧属性面板均可收起，每一侧只保留一个展开/收起入口，避免同一动作重复出现；需要专注查看流程时可以把两侧面板全部折叠。保存工作流后，节点位置会随工作流一起保存；再次打开或换一台设备登录，仍会看到上次保存的布局。

### 如何真实试运行工作流

1. 在设计器里通过表单配置节点和条件分支，也可从“流程设置”载入本场景可运行模板。节点 JSON 配置保留在高级选项中。
2. 点击右上角“试运行”，在右侧选择内置用例或填写业务输入。运行前检查会逐项列出缺失配置；有未保存修改时，可以直接“保存并开始运行”，保存成功后才执行。
3. 运行中，画布上的节点显示真实执行状态；刚走过的连线沿箭头方向显示流转动画，未走的条件分支不会亮起。右侧显示执行轨迹，点击步骤展开实际输入、输出、耗时或错误。
4. 如果到达“人工处理”节点，流程会停在“等待人工确认”，不会自动通过。管理员可以在运行面板中明确选择通过或拒绝：通过后继续同一次运行，拒绝则终止。运行失败时，修正配置并保存后重新试运行。
5. 运行结果会保存在“最近运行”中，可以查看最终输出或修改输入再次运行。关闭右侧测试面板可继续查看画布，待审批运行会在刷新后恢复。

最容易验证输入到输出的方式是新建一条“开始 → 结束”流程，输入一句问题并查看结束节点的输出。添加条件节点时，可使用 `{"field":"question","operator":"contains","value":"权限"}`，并为 `true` / `false` 分支分别连到目标节点；只有实际选中的边会流转。知识检索要选择含已完成索引文档的知识库；业务工具只开放明确配置的只读查询；模型节点会实际调用已配置的 DashScope 模型服务。测试输入和节点结果会写入运行记录，请勿填入密码、验证码或密钥。

## 全局搜索

点击页面顶部搜索框，或按 `Ctrl + K`，可以搜索：

- 会话名称
- 知识库与文档
- 业务场景
- 工作流
- 功能页面

点击结果会直接进入对应对象，不需要先切换菜单。

## 如何判断回答是否可信

优先检查三项：

1. 是否选择了正确知识库。
2. 回答下方是否有对应引用，引用片段是否支持结论。
3. 链路追溯中的工具是否查询了正确的客户、订单或工单。

如果资料不足、业务数据不存在或工具失败，系统应明确说明，而不是补造答案。涉及重大权益、账户安全、合同或政策例外时，以人工复核结果为准。
